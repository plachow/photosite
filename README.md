# PhotoSite

PhotoSite is a Windows-first photo catalogue and viewer focused on low-latency
browsing. The current repository contains the first vertical slice:

- recursive, cancellable folder indexing;
- a lazy Windows directory tree with restoration of the last selected folder;
- a persistent SQLite catalogue with warm-start loading and stale-entry cleanup;
- a virtualized tile panel that only realizes visible thumbnails;
- disk-cached thumbnails generated by PhotoSauce MagicScaler;
- an asynchronous viewer with zoom, pan, selection, crop, rotation and flip;
- clipboard bitmap documents with JPEG Save As;
- anonymous Imgur upload of the current edited image with URL copy;
- persisted ratings and non-destructive edit recipes.

## Build

Requirements:

- Windows 10 1809 or newer;
- .NET 10 SDK.

```powershell
dotnet build PhotoSite.slnx
dotnet run --project tests/PhotoSite.SmokeTests/PhotoSite.SmokeTests.csproj
dotnet run --project src/PhotoSite.App/PhotoSite.App.csproj
```

Runtime data is stored under `%LOCALAPPDATA%\PhotoSite`. Source photographs
remain unchanged unless the user explicitly chooses **Overwrite original**.

## Editor shortcuts

- `Ctrl+V` — open a clipboard bitmap as a new unsaved image;
- `Ctrl+Shift+S` — save the current image (pasted images use JPEG quality 90);
- `Ctrl+U` — upload the current edited image to Imgur and copy its direct URL;
- `Ctrl+Z` / `Ctrl+Y` — undo / redo;
- `C` — start region selection; `Enter` crops and `Ctrl+C` copies it.

The first Imgur upload asks for an Imgur application Client ID and stores that
non-secret identifier in PhotoSite's local settings.

## Architecture

The WPF surface is intentionally behind small controls and services. The first
slice uses WPF composition for the viewer while the catalogue, cache, persistence
and edit model are stabilized. A Direct3D 11/Direct2D renderer can replace
`PhotoViewer` without changing the catalogue or application model.

Work still planned:

- Vortice Direct3D 11/DXGI/Direct2D render surface;
- prioritized prefetch of adjacent photographs;
- ICC monitor-profile conversion;
- XMP/ExifTool durable metadata outbox;
- tiled rendering for images larger than a GPU texture;
- preview/export parity for tonal adjustments.
